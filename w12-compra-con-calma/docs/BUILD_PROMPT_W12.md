Handle failures visibly, bound inputs, render user text safely and include an explicit incomplete-draft label. Test blank versus zero, cents, malformed types, missing fields, over-limit lower bounds, saving, reload and deletion. No recommendations, loans, dimensions or automated purchases. Keep actual test failures and deployment receipts; do not invent user research, team proceedings or elapsed dialogue time.
